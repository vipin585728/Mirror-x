# MIRROR-X 🧠

## Your Digital Decision Twin

MIRROR-X is a web-based project that records your decisions and analyzes your decision-making patterns over time.

### ✨ Features

- 📝 Record personal decisions
- 📊 Decision analytics
- 🎯 Confidence tracking
- 🧠 Digital Decision Twin
- 📈 Choice consistency analysis
- 🕒 Decision timeline
- 💾 Local browser storage
- 📱 Responsive futuristic UI

### 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage

### 🚀 Project Idea

MIRROR-X studies the decisions a user makes and creates an experimental "Digital Decision Twin" based on their historical decision patterns.
